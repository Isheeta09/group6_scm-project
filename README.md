# Supply Chain Game HAN

A Streamlit-based educational supply chain simulation developed for HAN University of Applied Sciences.

The platform allows students to manage a virtual company through multiple business quarters, make cross-functional supply chain decisions, respond to disruption events, and evaluate performance using key supply chain KPIs.
---

# Educational Purpose
The application was developed as part of the Supply Chain Management programme at HAN University of Applied Sciences.

It aims to support:

* Experiential learning
* Cross-functional decision-making
* KPI-based performance management
* Supply chain resilience
* Strategic planning
* Reflection and continuous improvement
---

# ▶️ How to Run

## Step 1 — Install Python

Install Python 3.10 or higher:

https://www.python.org/downloads/

## Step 2 — Install Requirements

Open a terminal and run:

```bash
pip install -r requirements.txt
```

## Step 3 — Run the Application

```bash
streamlit run app.py
```

The application will open automatically in your browser.

# Main Features: 

### Multi-Quarter Simulation
* Eight-quarter business simulation
* Progressive learning objectives
* Dynamic business scenarios

### Departmental Decision-Making
Students make decisions across:

* Purchasing
* Operations
* Sales
* Supply Chain

### KPI Dashboard
Track performance using:

* Profit
* Service Level
* Inventory Value
* Sustainability Score
* Risk Score
* Lead Time
* Efficiency Score

### Scenario-Based Learning
Includes realistic disruption events such as:

* Port strikes
* Tariff increases
* Demand fluctuations
* Sustainability pressures

### Strategy Planning
Teams create strategic plans before making decisions and evaluate outcomes against their objectives.

### AI Learning Coach
Optional AI-generated feedback that:

* Explains KPI changes
* Supports reflection
* Connects outcomes to supply chain concepts

### Instructor Controls
* Instructor dashboard
* Department locking
* Progression management
* Scenario control
